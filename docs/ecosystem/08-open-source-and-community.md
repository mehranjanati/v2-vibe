# Open Source and Community Strategy (Canonical)

> **Status:** `adopted` 2026-11-21. License: `LICENSE` (MIT, preserved).

Core platform source stays open; Runtime supports self-hosting; Agent/Tool
SDKs plus APIs and protocol contracts are public; gateway supports many
providers; open-weight/local models first-class; proprietary APIs optional;
export of agents, configs, manifests, and data required; self-host needs no
Cloud; community integrations follow documented versioning; open specs
preferred. Commercial model: subscriptions, usage billing, enterprise support,
managed infra, premium ops, marketplace fees where lawful, optional network
fees. Model licensing distinguishes code openness from weight redistribution.
No license change is made by this consolidation.
