The M0–M6 platform strategy remains the engineering spine; the P0–P9 roadmap
(`ecosystem/03-product-roadmap.md`) extends it to Assistant, Research,
Commerce, Runtime portability, Network, and Web3 economy. Outcome-first,
one System IR, NL-first plus advanced visual, open core plus managed cloud,
runtime-enforced policy, durable observable execution, versioned systems.

## Web3 application direction (PROPOSED 2026-11-25)

The platform adds an AI-native Web3 application direction without changing
its identity: general-purpose agentic platform first, with Contract Studio
(specification, generation, compilation, testing, security analysis) and
Web3 Operations (wallet integration, transaction lifecycle, deployment
records, monitoring, cross-chain operations) as the Web3 product surfaces.
Smart Contract IR is separate from System IR; EVM is the first target;
LayerZero is a modular adapter; wallet-first signing is mandatory. Detail:
`ecosystem/11-web3-network-economy.md`, `architecture/web3-smart-contract-ir.md`,
`architecture/web3-chain-abstraction.md`,
`architecture/web3-layerzero-interop.md`,
`architecture/web3-toolchain-pipeline.md`,
`architecture/web3-security-signing.md`. All Web3 decisions stay PROPOSED
or OPEN; no engineering P-number changes in this pass.
